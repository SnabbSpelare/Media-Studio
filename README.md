# Media-Studio
Load hundreds of local photos, GIFs, and videos smoothly inside a browser. Everything runs locally in memory.

## Features

- **Local Media Gallery** — Load and browse hundreds of local images, animated GIFs, and videos directly in your browser.
- **Offline Operation** — No server, cloud storage, external services, or internet connection required.
- **Drag-and-Drop Import** — Import local media files directly into the gallery.
- **Media Deduplication** — Automatically detect and reject identical files using SHA-256 content hashing, regardless of filename.
- **Duplicate Visibility Control** — Optionally show or hide existing duplicate media entries through the `Show Duplicates` setting.
- **Interactive Lightbox** — View images, GIFs, and videos in an expanded media viewer.
- **Lightbox Backdrop Dismissal** — Close the lightbox by clicking outside the displayed media.
- **Media Filename Copying** — Click the displayed filename to copy it to the clipboard, with temporary visual confirmation.
- **Dynamic Browser Tab Identity** — Automatically generate a 48 × 48 favicon from the currently displayed media and dynamically update the browser tab title with the media filename.
- **Focus-Aware Favicon** — Automatically convert the media-derived favicon to grayscale when the browser window loses focus.
- **Focus-Aware Document Title** — Display the application name alongside the filename while focused and the filename alone while unfocused.
- **Theme-Aware Scroll Progress** — A thin, fixed-position progress indicator tracks vertical page scrolling and automatically follows the active theme.
- **Optional Scroll Progress Indicator** — Toggle the scroll progress bar through settings; enabled by default and automatically hidden when scrolling is unnecessary.
- **Persistent Settings** — Retain configurable application preferences across sessions.
- **Optimized Interactions** — Prevent redundant filter activation, unnecessary media refreshes, and visual flickering.
- **Light and Dark Themes** — Theme-aware interface styling with consistent visual integration.
- **Responsive Interface** — Designed for comfortable media browsing across different viewport sizes.
